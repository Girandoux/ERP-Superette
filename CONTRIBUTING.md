# 🤝 Contributing

## Mitwirken am Projekt „Gestion de Superette“

> [!NOTE]
> **Projektkontext**
>
> Dieses Projekt basiert auf einem realen Anwendungsfall einer kleinen Superette in Kamerun.
>
> Es wurde entwickelt, um Geschäftsprozesse wie Einkauf, Verkauf, Lagerverwaltung, Inventur und Kassenführung digital abzubilden.
>
> Obwohl das Projekt derzeit von einer Person entwickelt wird, sind Verbesserungsvorschläge, Fehlerberichte und fachliche Hinweise jederzeit willkommen.

# 👋 Willkommen

Vielen Dank für dein Interesse an diesem Projekt.

Jede Form der Unterstützung trägt dazu bei, die Qualität des Projekts weiter zu verbessern. Dazu gehören sowohl technische Beiträge als auch Hinweise zur Dokumentation oder Ideen für neue Funktionen.

---

# 🎯 Ziel dieses Dokuments

Dieses Dokument beschreibt die grundlegenden Regeln für Beiträge zum Projekt.

Es soll sicherstellen, dass neue Änderungen

- nachvollziehbar,
- gut dokumentiert,
- leicht verständlich
- und mit der bestehenden Projektstruktur vereinbar sind.

---

# 💡 Möglichkeiten zur Mitwirkung

Beiträge sind beispielsweise in folgenden Bereichen willkommen:

## 🐞 Fehler melden

Falls Fehler oder unerwartetes Verhalten auftreten, können diese über GitHub Issues beschrieben werden.

Eine gute Fehlerbeschreibung sollte enthalten:

- kurze Problembeschreibung
- Schritte zum Nachvollziehen
- erwartetes Verhalten
- tatsächliches Verhalten
- verwendetes Betriebssystem
- verwendete Python-Version

---

## ✨ Verbesserungsvorschläge

Neue Ideen sind jederzeit willkommen.

Beispiele:

- neue Funktionen
- Verbesserung der Benutzeroberfläche
- Optimierung der SQL-Abfragen
- Erweiterung der Power BI Dashboards
- Verbesserung der Dokumentation
- Performance-Optimierungen

# 📂 Projektstruktur

Bitte orientiere dich bei Änderungen an der bestehenden Projektstruktur.

```text
gestion-superette/
│
├── sql/
├── streamlit/
├── powerbi/
├── images/
├── docs/
├── data/
└── README.md
```

Neue Dateien sollten möglichst in den passenden Ordner eingeordnet werden und der bestehenden Struktur folgen.

---

# 💻 Coding Standards

Für alle Änderungen gelten folgende Grundsätze:

- gut lesbarer Code
- aussagekräftige Variablennamen
- klare Funktionen mit einer eindeutigen Aufgabe
- verständliche Kommentare bei komplexer Logik
- einheitliche Formatierung
- keine unnötigen Code-Duplikate
- bestehende Projektstruktur beibehalten

Der Fokus liegt auf wartbarem, nachvollziehbarem und sauber strukturiertem Code.
